# Archive

This directory contains historical development artifacts that are not part of the active Embodied Vision runtime or Kokomi Kernel integration contract.

| Path | Contents |
| --- | --- |
| `experiments/` | Superseded CPU/GPU YOLO camera and Flask prototypes |
| `tools/` | The former minimal HTTP POST inspection server |
| `legacy-requirements/` | Dependency snapshots for superseded YOLO-only environments |
| `docs/` | Historical setup notes retained for provenance |

Archived files are preserved as reference material and are not maintained, tested, or imported by the production entry point.
